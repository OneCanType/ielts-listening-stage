# 篇目数据规范

> 这份文档只讲一件事：**怎么往课件里加一节听力、改一节、删一节**，以及数据结构长什么样。
>
> 引擎怎么工作看 [开发规范](开发规范.md)。所有例子都能直接跑 `python3 tools/check-data.py` 验证。

---

## 1. 数据在哪

题库是单个 `<script id="data" type="application/json">` 块，位于主文件的中部、主逻辑之前：

```html
<script id="data" type="application/json">{"lessons":[ … ]}</script>
<script>
  const DATA = JSON.parse(document.getElementById('data').textContent);
  …
</script>
```

- 必须是**合法 JSON**（不能有注释、不能有尾逗号）。
- 改完保存，刷新页面即生效；也可以让脚本注入：
  `python3 tools/apply-data.py my-data.json`（`--demo` 换回自编示例）。
- 数据只决定「默认标注」，老师在页面上的增删改存在 `localStorage`，不会回写文件。
- 仓库根目录放的是**自编示例**（可公开）；真实题库建议放 `private/`，用脚本生成一份独立 HTML 上课用，别提交。

---

## 2. 顶层结构

```json
{
  "lessons": [
    {
      "id": "B1",
      "title": "第一节 租房住房",
      "sections": [ { …section… } ]
    }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `lessons[]` | array | 单元列表，决定顶栏的单元 Tab 顺序 |
| `lessons[].id` | string | 单元 id，唯一；节 id 的前缀 |
| `lessons[].title` | string | 单元中文标题（Tab 上显示） |
| `lessons[].sections[]` | array | 这个单元下的节 |

---

## 3. 节 `section`

```json
{
  "id": "B1-1441",
  "code": "1441",
  "part": 1,
  "title": "Enquiry about booking hotel room for event",
  "groups": [ … ],
  "transcript": [ … ]
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | 是 | **全局唯一**，建议 `<lessonId>-<code>`；所有本地状态（答案 / 标注 / 笔记 / 配图）都以它为 key |
| `code` | string | 是 | 显示用编号，顶栏副标题会按「3–4 位数字 = 剑桥号 + Test + Part」解析；非数字则原样显示 |
| `meta` | string | 否 | 覆盖副标题的显示文本，适合自编题 / 非剑桥来源，如 `"示例数据 · 自编对话"` |
| `part` | number | 是 | 1–4，显示用（Section 1–4） |
| `title` | string | 是 | 英文标题，页头和篇目卡显示 |
| `groups` | array | 是 | 题组，按题号升序 |
| `transcript` | array | 是 | 听力原文段落 |

### 3.1 编号约定（当前题库，仅供参考）

`code` 目前用「剑桥号 + Test + Part」：

- `1441` = 剑 14 · Test 4 · Part 1（4 位：剑号 2 位 + Test 1 位 + Part 1 位）
- `1641` = 剑 16 · Test 4 · Part 1
- `521` = 剑 5 · Test 2 · Part 1

引擎只在**显示**时解析 `code`；换成一节 `0001` 这类自编编号时，加一个 `meta` 字段写清楚来源即可（见 3 节表格）。`id` 必须唯一。

## 4. 题组 `group`

四种 `kind`：`gap` / `choice` / `multi` / `match`。共同字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `kind` | string | 见下 |
| `from` / `to` | number | 题号闭区间，必须与题型匹配（见各节） |
| `title` | string | 如 `Questions 1-7`，显示在题组头部 |
| `instr` | string | 题目说明，可按 `q-` 系列 key 做高亮 / 批注 |
| `boxTitle` | string | 可选，匹配题选项框标题；当前版本只在数据里保留，界面未渲染 |

**硬性要求**

1. 一节内所有题组的题号合起来**连续、不重复**（可以从 11 开始，但不能缺 12）。
2. `title` 的题号要与 `from/to` 一致（校验脚本会查）。
3. 题组的顺序就是显示顺序。

---

## 5. `gap`：填空 / 笔记 / 表格

```json
{
  "kind": "gap",
  "from": 1,
  "to": 4,
  "title": "Questions 1-4",
  "instr": "Complete the notes below. Write ONE WORD AND/OR A NUMBER for each answer.",
  "layout": [
    { "type": "h",    "text": "Booking a study room" },
    { "type": "line", "text": "Name: {{1}}" },
    { "type": "line", "text": "Student number: {{2}}" },
    { "type": "line", "text": "Room: {{3}}" },
    { "type": "table", "caption": "Session", "head": ["Day", "Time"],
      "rows": [["Monday", "{{4}} hours"]] }
  ],
  "answers": {
    "1": { "a": ["Chen"], "raw": "Chen" },
    "2": { "a": ["S4182"], "raw": "S4182" },
    "3": { "a": ["B12"], "raw": "B12" },
    "4": { "a": ["two", "2"], "raw": "two" }
  }
}
```

### 5.1 `layout[]` 的三种块

| type | 字段 | 渲染 |
| --- | --- | --- |
| `h` | `text` | 小标题 |
| `line` | `text`，可选 `bullet: true` | 一行；行首 `● • – -` 会自动变项目符号 |
| `table` | `caption?`, `head[]`, `rows[][]` | 表格；`head` 可省略 |

- 空位统一写 `{{n}}`，`n` 必须是 `from..to` 内的整数。
- 一个块里可以放多个空，也可以不放。
- `answers` 的键必须与 `{{n}}` 一一对应；少一个就会渲染出「没有答案」的空。

### 5.2 答案写法

```json
"7": { "a": ["cabins"], "raw": "cabins" }
```

- `a`：**可接受答案列表**（大小写不敏感、单复数变体、连字符变体都放进来）。导出参考答案和「答」按钮显示 `a.join(' / ')`。
- `raw`：展示用写法（可读性更好，如 `28th;28;` → `28th`）。可以省略，省略时显示 `a.join(' / ')`。
- 数字题把阿拉伯数字和英文写法都放进 `a`（如 `["two", "2"]`）。

## 6. `choice`：单选

```json
{
  "kind": "choice",
  "from": 5,
  "to": 6,
  "title": "Questions 5-6",
  "instr": "Choose the correct letter, A, B or C.",
  "items": [
    { "n": 5, "q": "Where is the study room?",
      "opts": ["on the ground floor", "on the first floor", "in the basement"],
      "a": "B" },
    { "n": 6, "q": "What must Mia bring?",
      "opts": ["her student card", "a laptop", "a form"],
      "a": "A" }
  ]
}
```

- `items` 数量必须等于 `to - from + 1`，`n` 依次递增。
- `opts` 2–5 个，界面自动编 A/B/C…
- `a` 是字母，必须在 `opts` 范围内。
- 题干和每个选项都可以划词标注（key 见开发规范 6.4）。

---

## 7. `multi`：多选

```json
{
  "kind": "multi",
  "from": 7,
  "to": 8,
  "title": "Questions 7 and 8",
  "instr": "Choose TWO letters, A-E.",
  "pick": 2,
  "opts": ["get to know colleagues", "learn from mistakes", "ask questions",
           "react to feedback", "enjoy challenges"],
  "a": ["A", "C"]
}
```

- `pick` 默认 2，表示这组占 **`pick` 个题号**：`from..from+pick-1`，所以通常 `to = from + pick - 1`。
- `a` 长度必须等于 `pick`，字母在 `opts` 范围内。
- 答案顺序不影响判分；界面按选中的字母顺序记录。

---

## 8. `match`：匹配（含地图题）

```json
{
  "kind": "match",
  "from": 9,
  "to": 11,
  "title": "Questions 9-11",
  "instr": "What is said about each facility? Choose THREE answers from the box.",
  "boxTitle": "Availability",
  "options": [
    { "k": "A", "t": "included in the cost" },
    { "k": "B", "t": "available at extra charge" },
    { "k": "C", "t": "not available" }
  ],
  "items": [
    { "n": 9,  "q": "swimming pool", "a": "C" },
    { "n": 10, "q": "gym",           "a": "A" },
    { "n": 11, "q": "tennis courts",  "a": "B" }
  ]
}
```

- 有 `options`：下方显示选项卡片；`options` 只有 `k` 没有 `t` 时显示字母按钮。
- `items` 数量必须等于 `to - from + 1`；`a` 必须在 `options` 的 `k` 集合内（没有 `options` 时必须是单个大写字母）。
- **地图题不是靠缺 `options` 判定的**：只要 `instr` 里出现 `label the map` / `label the plan` / `label the diagram`，就自动走地图版式（见 8.1）。

### 8.1 地图题

地图题 = `match` + `figure`，且 `instr` 里要写 `Label the map/plan/diagram`（引擎按这句话切版式）：

```json
{
  "kind": "match", "from": 15, "to": 20,
  "title": "Questions 15-20",
  "instr": "Label the map below. Write the correct letter, A–I, next to Questions 15-20.",
  "figure": "data:image/webp;base64,UklGR…",
  "items": [ { "n": 15, "q": "statue", "a": "E" }, … ]
}
```

- 图片建议 **宽 560–900px、WebP、≤120KB**，太大会挤爆 `localStorage`。
- 图里要有字母标记（A、B、C…），题目用同一个字母作答。
- 不需要 `options`；有 `options` 时会用它们的 `k` 作为圆点列（例如 A–I）。

## 9. `transcript`：听力原文

```json
"transcript": [
  { "spk": "LIBRARIAN",
    "text": "Good morning. How can I help you?",
    "marks": [] },
  { "spk": "MIA",
    "text": "I'd like to book a study room for two hours, please.",
    "marks": [
      { "s": 34, "e": 43, "cat": "answer", "q": 4 },
      { "s": 19, "e": 29, "cat": "locate", "q": 4 }
    ] }
]
```

| 字段 | 说明 |
| --- | --- |
| `spk` | 说话人标签，大写短名（ANDREW / MIA / NARRATOR），可选。独白类可整节不写 |
| `text` | 原文，保留原始标点、弯引号；不要手动换行 |
| `marks` | 默认标注数组，可省略 |

### 9.1 `marks[]`

```json
{ "s": 42, "e": 45, "cat": "answer", "q": 4, "note": "" }
```

| 字段 | 说明 |
| --- | --- |
| `s` / `e` | 段内字符偏移，`[s, e)`；**必须完整覆盖一个词或短语** |
| `cat` | `answer` / `distract` / `logic` / `locate` / `help` / `underline`（默认标注一般只用前四种） |
| `q` | 关联题号，可空 |
| `note` | 备注，可空 |

**坐标怎么数**

- 从 `text` 的第一个字符开始，`0` 开始计数，`e` 是结束位置（不含）。
- 是 JS 字符串下标（UTF-16 code unit）。英文文本基本等于「第几个字符」；有 emoji / 生僻字时要小心。
- 不要切在单词中间：`particular` 里的 `art` 不是合法边界。
- 大小写、弯引号按原文，不要替换成直引号。

**写标注的建议**

- `answer`：答案词本身（1–4 个词），尽量短。
- `distract`：同段出现的其他数字 / 价格 / 日期、被更正掉的内容。
- `logic`：however / but / actually / instead / so / because 等信号词及短语。
- `locate`：题干关键词在原文的落点（名词、地名、时间）。
- 一节 15–30 条足够；标太多学生看不见重点。

## 10. 配图 `figure`

- 放在题组上：`"figure": "data:image/webp;base64,…"`。
- 页面上的「替换 / 移除」会把图存进 `localStorage` 的 `T.figs["<secId>|<from>"]`，优先于数据里的 `figure`；空串表示老师显式移除。
- 支持的格式：任何浏览器能显示的 data URL；建议 WebP。
- 生成方法（macOS）：

```bash
python3 - <<'PY'
from PIL import Image
import base64, io
im = Image.open('map.png').convert('RGB')
im.thumbnail((900, 1200))
buf = io.BytesIO(); im.save(buf, 'WEBP', quality=88, method=6)
print('data:image/webp;base64,' + base64.b64encode(buf.getvalue()).decode())
PY
```

## 11. 新增一节：完整步骤

### 11.1 准备

1. 想清楚这一节：**几道题、哪几种题型、题号区间**。
2. 原文按「说话人一段」切好；答案在原文里能逐字找到。
3. 标注先画在纸上 / 脑内：哪几个词是答案、干扰、逻辑、定位。

### 11.2 写 JSON

最小可用模板（复制到 `lessons[].sections` 里，改字段即可）：

```json
{
  "id": "B1-9001",
  "code": "9001",
  "part": 1,
  "title": "Booking a study room",
  "groups": [
    {
      "kind": "gap", "from": 1, "to": 2, "title": "Questions 1-2",
      "instr": "Complete the notes below. Write ONE WORD AND/OR A NUMBER for each answer.",
      "layout": [
        { "type": "h", "text": "Booking" },
        { "type": "line", "text": "Name: {{1}}" },
        { "type": "line", "text": "Room: {{2}}" }
      ],
      "answers": {
        "1": { "a": ["Chen"], "raw": "Chen" },
        "2": { "a": ["B12"], "raw": "B12" }
      }
    },
    {
      "kind": "choice", "from": 3, "to": 3, "title": "Questions 3",
      "instr": "Choose the correct letter, A, B or C.",
      "items": [
        { "n": 3, "q": "How long does Mia book the room for?",
          "opts": ["one hour", "two hours", "three hours"], "a": "B" }
      ]
    }
  ],
  "transcript": [
    { "spk": "LIBRARIAN", "text": "Good morning. How can I help you?" },
    { "spk": "MIA", "text": "I'd like to book a study room for two hours. My name is Mia Chen.",
      "marks": [
        { "s": 34, "e": 43, "cat": "answer", "q": 3 },
        { "s": 56, "e": 64, "cat": "answer", "q": 1 }
      ] },
    { "spk": "LIBRARIAN", "text": "That's right. Room B12, for two hours." }
  ]
}
```

> 上面的 `s/e` 是真实可用的值（`two hours` = 34–43，`Mia Chen` = 56–64），可以对照 11.3 的脚本复算。

### 11.3 用脚本算标注坐标（推荐）

不要手数字符，写个一次性小脚本按词查找：

```python
text = "I'd like to book a study room for two hours. My name is Mia Chen."
for word, cat, q in [("two hours", "answer", 3), ("Mia Chen", "answer", 1)]:
    s = text.index(word)
    assert s >= 0
    assert not (s > 0 and text[s-1].isalnum())
    assert not (s + len(word) < len(text) and text[s+len(word)].isalnum())
    print({"s": s, "e": s + len(word), "cat": cat, "q": q})
```

`tools/check-data.py` 会再帮你验一遍边界。

### 11.4 校验

```bash
python3 tools/check-data.py ielts-listening-stage.html
# 或校验一份纯 JSON
python3 tools/check-data.py my-data.json
```

必须 **0 error**。warning 建议逐条看（多为「答案词在原文找不到」，可能是标注漏了或答案写法不同）。

### 11.5 页面验收

1. 刷新 → 顶栏能选到新节，标题 / 题号 / 计时区正常。
2. 每题都能作答、能点「答」看答案。
3. 点每个空格 / 题号，左侧能跳到对应句。
4. 「划词」各分类能标、能挖空、能删除。
5. 若加了图：图能显示、能放大、导出 PDF 有图。
6. 「导出PDF → 网页版」：连线（若有）和题目位置正常。

## 12. 修改与删除

### 12.1 改文字 / 改答案

- 改 `text` / `q` / `opts` 后，**原有标注坐标可能失效**，必须重算该段的 `marks`。
- 改 `answers` 后跑校验；`a` 与 `{{n}}` 必须一一对应。
- 改完默认标注后，决定要不要改 `DATA_VER`（开发规范 5.2）：改了 = 所有人看到新默认，但本机手工标注清零；不改 = 只影响没编辑过该篇的浏览器。

### 12.2 删除一节

1. 从 `lessons[].sections` 删掉该对象。
2. 该节的 `localStorage` 残留（`custom` / `qhl` / `answers` / `notes` / `figs`）不会自动清理，但不影响使用，可忽略；要清理就在控制台执行：

```js
Object.keys(T.custom).forEach(k => { if (!SECTIONS.some(s => s.id === k)) delete T.custom[k]; });
// qhl / answers / notes / figs 同理，改完 persist()
```

3. 检查 `T.idx` 是否越界（启动时会自动夹到 0）。

### 12.3 调整题号

尽量**不要**改已有节的题号：`answers` 的 key 是 `secId|题号`，`qhl` 与 `marks.q` 也都带题号，改了会错位。必须改时，改完让老师「初始化」该篇（或改 `DATA_VER`）。

## 13. 校验脚本会查什么

`tools/check-data.py` 的规则：

| 级别 | 检查 |
| --- | --- |
| error | `lessons` / `sections` 为空；lesson id、section id 重复；缺 `code/title/part/groups/transcript` |
| error | 题组 `from > to`；同节题号重复或断号；`title` 里的题号与 `from/to` 不一致 |
| error | `gap`：`{{n}}` 与 `answers` 键不一致；答案为空；`a` 不是非空数组 |
| error | `choice`：`items` 数量 ≠ 题号数；`n` 不连续；`opts` 少于 2 个；`a` 越界 |
| error | `multi`：`pick` 与 `a` 长度不一致；题号数 ≠ `pick`；`a` 越界 |
| error | `match`：`items` 数量 ≠ 题号数；`a` 不在 `options[].k` 里 |
| error | `marks`：`s >= e`、越界、切在单词中间、`cat` 未知、`q` 不在本节题号内 |
| warning | gap 答案在原文里找不到（可能是拼写 / 同义替换，需人工确认） |
| warning | `figure` 不是 data URL；图片 base64 过大（> 300KB） |

退出码：`0` 无 error；`1` 有 error。

## 14. 常见错误

| 现象 | 原因 |
| --- | --- |
| 页面整片空白 | JSON 不合法（多逗号、注释、引号没转义） |
| 题号显示跳跃 | `from/to` 与 `items` 数量不匹配 |
| 某题没有输入框 | `{{n}}` 漏写或题号超出 `from..to` |
| 点「答」没反应 | `answers` 少键，或 `a` 为空 |
| 挖空是半个词 | `s/e` 没对齐单词边界 |
| 高亮错位一格 | 改过 `text` 但没重算 `marks` |
| 新默认不生效 | 没改 `DATA_VER`，旧缓存还在（或该篇有 `T.custom` 快照） |
| 地图不显示 | `figure` 不是 data URL，或被本地 `T.figs` 的空串覆盖 |
| 导出丢连线 | 题目端的 `qhl.key` 在渲染时找不到（key 拼错） |
