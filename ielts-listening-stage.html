导出 PDF 课件

打印窗口里选择「另存为 PDF」。导出当前这一节：标记 + 已填答案 + 替换连线 + 笔记。

版式

你填在页面上的答案（蓝色下划线）始终会导出；「参考答案」默认不显示。所有彩色标注、高亮、下划线、替换释义都会保留。
网页版在打印预览里会显示成一张很高的自定义纸（例如 210 × 530 mm），不用改设置，直接「另存为 PDF」就行；要打印到 A4 纸请选「A4 单栏」。

投影 / 演讲者视图

另开一个窗口放到投影屏：布局和本窗口一样是左右两栏，内容实时镜像。

  1. 系统显示设置里把投影设成 扩展（Extended），不要用「镜像 / 复制」，否则两块屏画面一样。
  2. 点下面按钮打开投影窗口；若浏览器询问「查看你的屏幕」权限，选允许，它会自动落到第二块屏（拒绝也行，手动拖过去）。
  3. 在投影窗口里双击画面即可全屏（Windows 也可 F11，Mac 用 ⌃⌘F）。投影和本窗口一样是左右两栏，文稿默认隐藏；要给学生看原文时，点投影窗口上方的「显示文稿」。中间的分隔条可以左右拖动。

切换篇目、标注、高亮、笔记、替换连线、字号、左右分栏与滚动都会自动同步到投影窗口。

使用说明

课堂课件：左侧文稿、右侧题目；改动自动保存在当前浏览器，需要时导出 PDF。

课堂展示

左侧为听力文稿，右侧为题目。点顶栏「显示文稿」打开原文；带颜色的标注词默认是彩色空格，点击显示；「答」按钮显示参考答案，用于课堂讲解。图例五个按钮可整类显示或挖空。

文稿标注 / 下划线

图例那一行有「划词」工具：答案 / 干扰 / 逻辑 / 定位 / 自定义 / 替换。点一下进入该类标注模式，再去文稿里划词，松手就直接标上，不再弹小窗；可以连着划很多处，按 Esc 或再点一次按钮退出。

没有选类别时，划词会浮出小菜单，里面是 下划线：紫色实线，始终显示、不挖空，适合标语法结构或固定搭配；点一下这条下划线可以改类别或删除。文稿这一侧不再有 Note，需要写字时用顶栏的「笔记」面板。

自定义是青色下划线，不挖空：标出定义、举例、更正、拼写提示等你认为值得讲的内容；不会自动生成，全部由老师手动选「自定义」。

替换（同义替换连线）在「划词」工具里：点 替换 → 在文稿里划词 → 再去题目里拖选对应的一段 → 泡泡里写中文释义（可留空）。两端是粉色虚线、中间有连线；点任意一端可改释义或删除。想换掉文稿这一端，直接重新拖选即可；按 Esc 或点提示条上的「取消」退出。

也可以反过来：先在题目（含选择题选项）里选中一段 → 点浮出的 ⟷ 替换 → 再回文稿里拖选原文。两个方向做出来的连线完全一样。

写了中文释义后，释义会直接以粉色小泡泡挂在连线上（字号跟着页面字号一起缩放，A+ / A− 也一起变）。按住泡泡可以顺着连线拖动，拖到空处就不会挡住正文；点一下泡泡可以重新编辑。多个连线的泡泡会自动错开。

文稿图例右侧的 ↶ 撤销 / ↷ 重做 只回退左边文稿的标注（彩色标注、下划线、替换连线、备注），不会动题目上的高亮和笔记。

点题目 → 原文自动定位

右侧题目点一下就会把左边文稿滚到答案句并闪一下：填空题点那个空格（输入框），选择 / 多选 / 匹配 / 地图题点题号。文稿本来是收起的，会自动展开。答案句优先用原文上标好的答案词定位，没有标注时按答案词在原文里搜；实在找不到会提示「没找到对应答案句」。

题目 Highlight / Note

题目区不需要点任何标记按钮：直接选中文字就会浮出 Highlight / Note；在题目上点 Note 会打开右侧的题目笔记页（一条条对应题目原文）。题目上的改动用 Ctrl+Z 撤销（会按你最后改的是哪一边自动判断）。

课堂笔记（富文本面板）

顶栏「笔记」打开一个独立的富文本笔记窗口，用法和 Word 类似：段落样式（正文 / 标题 1–3 / 引用 / 代码块）、字号、加粗、斜体、下划线、删除线、文字颜色、底色高亮、有序 / 无序列表、缩进、左中右对齐、分隔线、清除格式、撤销 / 重做都有。

面板可以拖标题栏移动、拖右下角改大小、点 ⛶ 全屏放大；每篇独立保存（切篇目自动切换内容），停止输入半秒后自动存到本机，底部显示字数和保存时间。导出 PDF 时勾选「包含笔记」会把这篇的富文本笔记一起打出来。

投影时学生也能看到这个笔记：你在自己屏幕上打开 / 移动 / 缩放 / 滚动笔记面板，投影窗口里会出现位置、大小、内容、滚动位置都一致的一份（只读）。关掉面板，投影里也一起消失。

选择题的选项文字同样可以划词标注（也能作为替换连线的题目一端）。作答只认选项左边的圆点（多选是方框）：点选项文字不会把答案选上，只有点圆点 / 方框才选上，再点一次取消。

地图 / 平面图 / 图表题的配图

地图、平面图、图表这类题的版式是左边配图、右边字母表：在表格里点 A–I 下面的圆圈作答，再点一次取消；题号下面的小「答」可以看参考答案。

1522 Minster Park、1422 Branley Castle、1122 剧场平面图这三张图已经内置在文件里，打开就有。其它题如果缺图，左边会显示「本题需要配图」：复制图片后直接按 Ctrl / ⌘ + V 就会贴到眼前这个缺图位，也可以点「选择图片」或把图片拖进来。

加好的图会自动压到合适大小存到本机，导出 PDF 时图会一起打出来，投影里也有。鼠标移到图上可以「放大 / 替换 / 移除」，点图片本身也能放大看。

初始化 / 清空笔记

存为初始（右上角）：把当前所有篇目的标记与题目批注存成新的初始状态；以后初始化、刷新、重开都会回到这份，老师改过的内容不会退回内置默认。

初始化在它旁边：回到「存为初始」存下的那份状态（还没存过就是内置默认），并清空已填答案；可选「初始化本篇」或「初始化所有篇目」。

清空所有笔记点开可选「清空本篇」或「清空全部」，会清掉题目的 Note 和两边的同义替换释义（连线两端一起删）；彩色标注 / 高亮 / 答案都不动。富文本「笔记」面板的内容不在这个范围内，要清就在面板底部点「清空本篇」。

保存 / 导出 / 退出

顶栏「保存」直接存到当前浏览器，刷新/重开本页仍在。文稿侧和题目顶部也各有本页保存按钮。

「导出PDF」→ 打印窗口里选「另存为 PDF」，导出当前这一节。版式有两种：网页版（默认）和网页一样左右两栏，文稿在左、题目在右，同义替换的粉色连线和连线上的释义泡泡都会画出来，整节排成一张很高的页（不用翻页），最适合存档和屏幕阅读；A4 单栏会自动分页、省纸，适合打印到纸上，不含左右排列和连线。两种版式都会带上：听力文稿的全部彩色标注、题干与选项上的高亮 / 下划线 / 替换释义、你填在页面上的答案（蓝色下划线）、课堂笔记面板里的富文本内容和题目批注。参考答案默认不打印，需要时勾选「额外显示参考答案」。点「退出」时如果有未保存改动，会问「保存并退出 / 不保存退出」。

投影 / 演讲者视图

顶栏「投影」会另开一个窗口放到投影屏。它和本窗口是同一套布局：左右两栏、中间可拖动分隔条；文稿默认隐藏，要给学生看原文时点投影窗口上方的「显示文稿」（本窗口文稿图例里的按钮也能切换）。

投影里的字号（投影里也有 A− / A+）、左右分栏、滚动位置、题目与文稿的标注 / 高亮 / 笔记 / 替换连线 / 已填答案 / 揭晓的答案都和本窗口实时同步；在投影窗口里滚动或拖分隔条，本窗口也会跟着变。投影里不显示「保存 / 答 / 清空」这些老师专用按钮。

两个笔记面板也会投上去：顶栏「笔记」的富文本笔记、题目区「题目笔记」打开的面板，只要你在自己屏幕上打开，投影窗口就会在相同位置显示同样的内容（位置、大小、滚动都按比例同步，只读、不能点）。适合让学生一起看你写的板书要点。
